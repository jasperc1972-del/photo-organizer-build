# 照片整理工具（含自動打包腳本）

依照片的拍攝日期（EXIF，若無則用檔案修改時間），把照片複製到「年-月」資料夾。原始照片不會被移動或修改。

## 檔案說明

| 檔案 | 說明 |
|---|---|
| `photo_organizer_auto.py` | 視窗版（Tkinter），打包成 exe 後雙擊即可執行 |
| `organize_photos.py` | 命令列版 |
| `build.py` | 自動打包腳本，把視窗版打包成 `dist/照片整理.exe` |

## 安裝套件

```
python -m pip install pillow pyinstaller
```

## 打包成 exe

```
python build.py
```

完成後會產生 `dist/照片整理.exe`。打包失敗時，舊的 exe 不受影響，畫面會顯示錯誤排除建議。

## 使用 exe

1. 把 `照片整理.exe` 放到一個資料夾。
2. 在同一個資料夾建立 `舊照片` 資料夾，把要整理的照片放進去。
3. 雙擊 `照片整理.exe`。
4. 整理結果在 `整理後照片` 資料夾，詳細清單在 `整理後照片/整理結果.txt`。
